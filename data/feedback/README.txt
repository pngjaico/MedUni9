Este diretório é gerenciado automaticamente pelo agente de feedback.

- incoming/   -> Feedback bruto dos usuarios (coletado do Firestore)
- approved/   -> Feedback bruto aprovado por voce para gerar plano
- denied/     -> Feedback bruto negado por voce
- plans/      -> Planos de acao pendentes para segunda aprovacao
- processed/  -> Feedback aprovado que ja virou plano
- archived/   -> Planos aprovados ou negados no segundo passo
