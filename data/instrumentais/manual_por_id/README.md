# Imagens manuais por instrumental

Cada subpasta usa o **mesmo `id`** que em [`data/to_instrumentais.json`](../../to_instrumentais.json) (ex.: `pinca_kelly_curva`).

1. Guarde a melhor imagem em `data/instrumentais/manual_por_id/<id>/` (PNG ou JPG).
2. Pode haver vários ficheiros; quando for integrar ao app, convém um ficheiro canónico (ex.: `principal.png`).
3. Os `mesa_*.png` do PDF continuam na pasta pai (`data/instrumentais/`) até alguém copiar/processar destas pastas para os paths do JSON.
